# Forex Super Study Terminal

This project is an educational site that:
- Displays a live forex chart (EUR/USD).
- Runs textbook tactics (Moving Average, RSI, MACD, Bollinger Bands).
- Analyzes forex news sentiment.
- Shows a dashboard signal board with consensus prediction.

## Resources Included
- TradingView widget for live charts
- Alpha Vantage API for forex price data
- NewsAPI for forex-related headlines
- JavaScript implementations of textbook tactics
